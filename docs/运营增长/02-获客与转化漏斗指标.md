# 获客与转化漏斗指标

## 1. 原则

每个指标必须有定义、时间窗口、去重规则、数据来源和负责人。不要把页面访问、注册、试用和真实活跃混为一谈。

## 2. 漏斗阶段

### 访问

有效访问：排除机器人、内部测试和明显重复刷新后的站点会话。记录来源、落地页、设备和主要行为，不收集不必要个人信息。

### 意向行为

包括进入 Demo、完成一个 Demo 问题、查看价格、播放演示视频 50% 以上、开始填写预约或试用表单。

### 线索

已提交可联系信息并同意隐私条款。重复手机号/微信/邮箱按企业和时间窗口合并。

### 有效线索

符合目标行业/规模，存在相关问题，有可联系的负责人，并愿意进一步沟通。无法联系或纯求职/推广不计有效。

### 预约演示

双方确认日期和参与人。只填表但没有确认时间不算完成预约。

### 完成演示

客户实际参加并完成需求沟通与产品演示。

### 试用

租户已开通，目标、负责人、周期和成功标准已确认。仅创建账号不等于有效试用。

### 激活

导入或创建真实数据，至少两名真实用户，并完成首周成功事件 70% 以上。

### WAAC

企业一周内完成以下任意 3 项：新增客户、写跟进、建报价、建订单、出入库、处理应收、使用 AI 查询、处理项目、处理工单或使用企微。

### 报价

正式报价已发送，包含范围、价格、有效期和决策节点。

### 付费

合同生效且按约定收到首笔款。口头同意不计付费。

## 3. 核心转化率

- Demo 进入率 = Demo 会话 / 有效访问。
- 线索转化率 = 线索 / 有效访问。
- 有效线索率 = 有效线索 / 线索。
- 演示预约率 = 已确认预约 / 有效线索。
- 演示出席率 = 完成演示 / 已确认预约。
- 试用转化率 = 有效试用 / 完成演示。
- 首周激活率 = 激活企业 / 有效试用。
- 报价率 = 正式报价企业 / 激活企业。
- 成交率 = 付费企业 / 正式报价企业。

每个比例同时展示分子和分母，小样本期不只看百分比。

## 4. 时间指标

- 线索首次响应时间。
- 线索到演示时间。
- 演示到试用时间。
- 试用到首个真实业务动作时间。
- 试用到激活时间。
- 激活到报价、报价到成交时间。

早期比平均值更应观察每家企业的实际路径和异常原因。

## 5. 渠道归因

保存首次来源、最近来源和关键转化来源。渠道包括自然搜索、视频号、抖音、小红书、公众号、社群、转介绍、合作伙伴、线下活动和直接访问。

来源不明时标记 unknown，不能为了报表完整而猜测。

## 6. 产品使用指标

- 活跃企业和 WAAC。
- 各模块真实业务单据企业数。
- AI 周活企业、问题数、成功回答率、下钻率和确认动作率。
- 数据导入成功率和人工修复量。
- P0/P1 阻塞、首次解决时间和复发率。

AI 问题数不能单独代表价值，应结合是否使用真实数据、查看来源和完成业务动作。

## 7. 每周看板

每周至少展示：新增有效线索、预约、完成演示、有效试用、首周激活、WAAC、报价、付费、主要来源、主要流失阶段和前三阻塞。

## 8. 每两周复盘

依次回答：流量是否来自目标客户、演示是否产生试用、试用是否激活、激活是否产生报价、报价为何成交或流失。

漏斗前端增长但后端激活下降时，不应继续放大流量。

## 9. 隐私与数据质量

- 敏感表单内容不写入分析事件。
- 内部测试流量使用单独标识并排除。
- 指标版本变更记录生效日期，历史数据不静默重算。
- 删除请求同步处理线索系统和分析中的可识别数据。
