# erp.starmin.cn 官网 V2 设计方案

版本：V2.0  
核心目标：获客、演示、留资、免费体验和共创客户转化。  
核心原则：先讲客户问题和业务结果，再讲功能；AI 是产品主角，但所有 AI 表达必须落到真实业务数据。

## 1. 转化目标与信息架构

### 主要转化

1. 进入无需注册的 Demo。
2. 预约产品演示。
3. 申请 14 天免费体验。
4. 申请成为共创企业。

### 顶部导航

首页、AI ERP、解决方案、价格、客户案例、帮助中心；右侧放登录、预约演示、免费体验。

CRM、OA、库存、MCP、工作流、知识库等不作为一级导航。移动端导航折叠，但固定保留“免费体验”按钮。

## 2. 首页结构与文案

### Section 01：Hero

标签：AI Native Enterprise Software

主标题：

> 企业经营  
> 直接问 AI

副标题：

> 客户、销售、报价、订单、采购、库存、应收和项目统一管理。让 AI 帮你查数据、发现问题、分析经营，并进一步处理业务。

主按钮：免费体验  
次按钮：预约产品演示  
辅助信息：14 天体验 · 无需信用卡 · 支持 Excel 导入 · 支持企业微信

右侧不是普通后台截图，而是“AI 企业助手”动态卡片：

> 用户：公司今天有什么需要我注意的？

AI 按 Demo 基准数据返回逾期应收、超期未跟进客户、低库存和延期项目，并展示“查看逾期应收”“安排客户跟进”“生成采购建议”三个动作。CRM、订单、库存、项目、财务节点以细线连接 AI，表达 AI 位于业务数据中央。

### Section 02：客户痛点

标题：企业不是没有系统，而是数据散在不同地方。

六张卡片：客户资料、销售进度、订单重复录入、库存不可见、应收无人提醒、管理仍靠 Excel。底部总结：星敏 AI ERP 的目标，是把这些数据重新连起来。

### Section 03：完整业务链

标题：从客户到回款，一个系统跑完整个业务。

流程：市场线索 → 客户 → 商机 → 报价 → 销售订单 → 采购 → 库存 → 发货 → 应收/收款 → 售后 → 经营分析。AI 贯穿全部节点。

下方用六个能力摘要说明 CRM、销售、采购、库存、财务协同和经营分析，不展开功能目录。

### Section 04：AI 理解业务

标题：这不是给 ERP 加一个聊天机器人。  
大字：AI 可以理解你的业务。

按角色展示六个问题：

- 老板：这个月经营情况怎么样？
- 销售：今天哪些客户最值得跟进？
- 财务：哪些应收已经超过 30 天？
- 仓库：哪些 SKU 最近可能缺货？
- 项目经理：哪些项目已经延期？
- 管理层：帮我生成本周经营报告。

用简短对比说明从“进入系统 → 找模块 → 设条件 → 导 Excel → 分析”变为“问 AI → 得到答案 → 继续处理”。

### Section 05：AI 不止回答，还能办事

标题：从 AI 问答，进一步走向 AI 执行。

演示一：找出超过 15 天未跟进且商机金额大于 5 万的客户 → 汇总金额 → 为负责人创建跟进任务 → 显示确认清单 → 用户确认 → 创建成功。

演示二：查询低库存 SKU 的销量和可用库存 → 预测缺货时间 → 生成采购建议草稿。页面明确突出“查询 → 判断 → 行动”，写操作默认需要确认。

### Section 06：与传统 ERP 对比

对比维度包括查询数据、数据分析、客户跟进、库存风险、应收风险、企业知识、操作入口和外部 AI 连接。避免贬低竞品，重点陈述体验差异。

MCP 只写为：“已有自己的 AI、Dify 或自动化系统？企业版支持安全连接业务数据。”

### Section 07：解决方案

首期仅展示四类：

- 贸易企业：CRM + 销售 + 采购 + 库存 + 财务协同 + AI。
- 外贸企业：增加多币种、汇率、装箱、海外客户和代收场景。
- 设备销售企业：设备 + 耗材 + 项目 + 售后 + 客户生命周期。
- 汽配/工业品企业：大量 SKU、多规格、客户价格、采购库存和频繁报价。

### Section 08：企业微信移动办公

标题：不在电脑旁，也能处理重要业务。  
主张：手机上，只放现在必须处理的事情。

展示销售写跟进、经理审批与预警、老板查看关键风险，不宣传“把整个 ERP 搬到手机”。

### Section 09：微信 AI 客服

作为辅助能力展示：客户询价 → 按等级返回价格 → 查询可售库存 → 生成报价草稿 → 必要时人工接管。说明可与 CRM、报价和订单一起使用。

### Section 10：Excel 导入

标题：你原来的 Excel，不需要全部推翻。

视觉流程：客户.xlsx / 产品报价.xlsx / 库存.xlsx / 应收.xlsx → AI 字段识别 → 星敏 AI ERP。CTA：导入我的 Excel。

不得承诺“完全无需整理”或“100% 自动导入”；应表达为自动识别、用户确认、错误预览和可回滚。

### Section 11：Demo

标题：不注册，先看看真实企业怎么用。

展示“星海智能设备有限公司”：30 名员工、100+ 客户、120 SKU、3 个仓库、30+ 销售订单、20+ 应收、10 个项目。提供六个快捷问题：本月销售额、待跟进客户、逾期应收、低库存、延期项目、本周经营报告。

按钮：进入 AI ERP Demo。

### Section 12：上手流程

四步：创建企业（约 1 分钟）→ 选择业务模块 → 导入 Excel/CSV → 开始问 AI。

### Section 13：套餐

## 3. 视觉规范

- 风格：现代 AI SaaS、专业、企业级、大量留白，避免传统 ERP 后台感。
- 主色：`#2563EB`；辅助色：`#4F46E5`；AI 高光：`#7C3AED`；成功：`#10B981`。
- 浅色背景：`#F8FAFC`；深色区域：`#0F172A`。
- 卡片圆角 16～24px，浅边框和轻阴影；避免大面积玻璃拟态影响可读性。
- 正文最大宽度约 1200px；桌面端 Hero 左 45%、右 55%；移动端先文案后 Demo。
- 动效只用于表达 AI 数据连接和回答生成，尊重 `prefers-reduced-motion`。
- 所有图片提供替代文本；正文对比度、焦点状态和键盘访问符合 WCAG 2.1 AA。

## 5. 表单与数据追踪

表单必须包含来源页面、UTM、提交时间和隐私同意；成功后进入 CRM 并创建跟进任务。防重复提交、限流、服务端校验和失败重试必须有明确反馈。

关键事件：Hero CTA、Demo 进入、Demo 快捷问题、预约提交、试用提交、套餐 CTA、共创申请、视频播放 50%、滚动至价格区和表单成功。

漏斗：访问 → Demo/预约 → 有效线索 → 演示 → 试用 → 激活 → 报价 → 付费。

## 6. SEO 与内容基础

- 每页唯一 title、description、canonical 和社交分享图。
- 使用语义化标题，首页仅一个 H1。
- 首批关键词围绕 AI ERP、贸易公司 ERP、设备销售管理、进销存 AI、ERP Excel 导入等真实需求。
- 配置 sitemap、robots、结构化数据和可索引的 FAQ。
- 不伪造客户 Logo、评价、使用数量和安全认证。

## 7. 性能与安全验收

- 移动端优先；目标 Core Web Vitals 达到良好区间。
- 首屏图片压缩并按尺寸加载，非首屏延迟加载，避免动画阻塞主线程。
- 表单数据加密传输，敏感字段不进入前端日志或分析平台。
- Demo 与真实租户完全隔离；Demo 写操作自动重置或仅生成草稿。
- AI 回答展示数据更新时间、权限边界和可追溯来源。

## 8. 发布验收清单

- 桌面与主流手机尺寸无错位，导航、CTA、表单和 Demo 可用。
- 所有对外数字与 `docs/Demo方案` 一致。
- 所有按钮有目标，无空链接；错误、加载、空状态完整。
- 表单成功进入 CRM，来源追踪正确，重复提交不会产生多条线索。
- 隐私、协议、数据安全和价格说明经过业务负责人确认。
- Lighthouse、可访问性、SEO、埋点和回归测试通过。
