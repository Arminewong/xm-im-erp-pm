# 星敏 AI ERP 上市执行总清单

本清单把 90 天计划转换为可逐项确认的交付物。每项应记录负责人、目标日期、实际日期、证据链接和阻塞原因。

## P0：对外演示前

- [ ] 品牌名、Slogan、目标客户和第一销售场景已统一。
- [ ] 官网 V2 文案、价格和 CTA 经过负责人确认。
- [ ] 星海智能 Demo 快照可稳定重置。
- [ ] 60 个 AI 演示问题完成内部验收。
- [ ] Demo 汇总数字能下钻并反向复算。
- [ ] 老板、销售、采购、仓库、财务、项目和售后角色权限已验证。
- [ ] AI 写操作全部先预览、再确认且可撤销。
- [ ] Demo 不发送真实短信、邮件、微信或企微消息。
- [ ] Excel 导入支持预览、字段确认、错误提示和回滚。
- [ ] 预约演示、免费体验、共创申请表单可真实落入线索系统。
- [ ] 隐私政策、用户协议、试用说明和数据处理边界已确认。
- [ ] 备份、恢复、租户隔离、审计、限流和 AI 用量限制经过检查。

## 官网发布

- [ ] 首页 16 个 Section 完成并通过移动端检查。
- [ ] `/demo`、`/trial`、`/contact`、`/pricing` 路由可用。
- [ ] 所有 CTA 有真实目标，无空链接和假提交。
- [ ] 页面 title、description、canonical、社交分享图、sitemap 和 robots 完成。
- [ ] 关键事件和来源参数可追踪，且不采集敏感表单内容。
- [ ] 客户 Logo、评价、案例和效果数字都有授权与依据。
- [ ] 价格标注“起”，并说明用户、模块、AI 用量和实施范围影响。
- [ ] 404、错误、加载、空状态和重复提交完成回归。

## 销售准备

- [ ] 5、15、30 分钟演示均完成至少 3 次内部演练。
- [ ] 销售演示稿控制在 10 页以内。
- [ ] 一页产品介绍可发送或打印。
- [ ] 需求访谈表、试用成功清单和演示记录已建立。
- [ ] 标准套餐、实施服务、付款方式和合同边界已确认。
- [ ] 常见异议和禁止承诺已完成内部培训。
- [ ] 演示失败时有录屏和离线材料备用。

## 种子客户招募

- [ ] 整理不少于 30 家符合画像的候选企业。
- [ ] 每家候选企业记录来源、行业、规模、联系人和可能痛点。
- [ ] 第一批完成不少于 10 次有效沟通。
- [ ] 完成不少于 5 次产品演示。
- [ ] 至少 5 家进入真实试用。
- [ ] 每家试用企业指定客户负责人和星敏负责人。
- [ ] 每家确定首周成功事件和 30 天成功标准。
- [ ] 数据使用、案例授权和试用退出方式已书面说明。

## 客户试用

- [ ] Day 0 完成账号、权限、数据和培训验收。
- [ ] Day 1～7 跟踪首个核心动作和阻塞。
- [ ] Day 7 完成用户访谈和现场任务观察。
- [ ] Day 8～30 验证是否跨角色、重复使用和持续录入。
- [ ] 所有反馈按 P0/P1/P2/P3/暂缓分类。
- [ ] 客户原话、实际行为和销售判断分开记录。
- [ ] 试用到期前完成价值复盘和正式报价。
- [ ] 不购买客户的数据按约定导出、删除或保留。

## 内容营销

- [ ] 首批 10 条视频完成拍摄和发布计划。
- [ ] 每条视频只有一个核心观点和一个 CTA。
- [ ] 视频中的 Demo 公司明确标记为演示数据。
- [ ] 建立曝光、3 秒留存、完播、Demo 点击、预约和有效线索统计。
- [ ] 不以播放量替代有效线索和成交评估。
- [ ] 完成至少一篇 Excel 改造长文和一篇 AI ERP 实操文章。
- [ ] 真实案例发布前完成客户审阅与授权。

## 商业验证

- [ ] 至少 5 家导入真实业务数据。
- [ ] 至少 3 家持续使用超过 30 天。
- [ ] 至少 2 家完成付费。
- [ ] 至少 1 家形成公开或匿名标杆案例。
- [ ] 明确 1～2 个客户愿意持续付费的核心卖点。
- [ ] 明确主要流失原因、成交阻塞和非目标客户特征。
- [ ] 每两周复盘 WAAC、试用激活、报价和成交。
- [ ] 下一季度路线图只围绕经过验证的价值制定。

## 发布决策

只有在 P0 安全、权限、Demo 隔离、表单真实落库和法律文本确认完成后，才进入公开推广。某项不能完成时，记录可接受的临时方案、负责人和最晚修复时间；涉及数据安全和租户隔离的项目不得带风险发布。
