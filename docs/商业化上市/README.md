## 当前商业化原则

1. 从“功能驱动开发”切换为“客户驱动验证”。
2. 先跑通 CRM → 报价 → 销售订单 → 采购 → 库存 → 发货 → 应收 → 售后主链路。
3. 官网和演示优先表达“AI 使用企业数据并协助办业务”，不堆叠模块名。
4. 前 90 天以真实活跃企业、付费客户和标杆案例为主要结果，不以注册量为核心。
5. 所有对外数据、截图和 AI 回答统一使用 `docs/Demo方案` 中的基准数据。
