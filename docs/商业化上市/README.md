# 星敏 AI ERP 商业化上市文档索引

本目录用于统一管理星敏 AI ERP 从产品项目走向可销售产品所需的定位、计划和验证材料。

## 核心文档

- [90 天上市计划](./01-90天上市计划.md)：按 0～14、15～30、31～60、61～90 天拆解目标、交付物和指标。
- [产品定位与市场策略摘要](./02-产品定位与市场策略摘要.md)：统一对外定位、目标客户、价值主张、定价和获客策略。

## 关联目录

- `docs/官网V2`：官网信息架构、页面文案、交互和验收要求。
- `prompts/cursor`：可直接交给 Cursor 执行的母 Prompt 与分阶段 Prompt。
- `docs/Demo方案`：星海智能设备有限公司 Demo 租户设定、造数规则与 AI 演示问题。

## 当前商业化原则

1. 从“功能驱动开发”切换为“客户驱动验证”。
2. 先跑通 CRM → 报价 → 销售订单 → 采购 → 库存 → 发货 → 应收 → 售后主链路。
3. 官网和演示优先表达“AI 使用企业数据并协助办业务”，不堆叠模块名。
4. 前 90 天以真实活跃企业、付费客户和标杆案例为主要结果，不以注册量为核心。
5. 所有对外数据、截图和 AI 回答统一使用 `docs/Demo方案` 中的基准数据。
