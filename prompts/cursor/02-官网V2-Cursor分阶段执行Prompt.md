状态：已完成。

## 阶段 2：Hero AI Demo 与统一 Demo 数据

验收：至少 6 个快捷问题可稳定重放；数字口径一致；加载、失败、重试和减少动态效果状态可用；Demo 不触达真实租户。

验收：路由可访问；导航和面包屑正确；内容符合目标行业；无虚假背书。

验收：合法、非法、重复和接口失败四类用例通过；成功线索可在目标系统核验；来源参数完整。

验收：关键页面可索引；事件不含个人信息；移动端 Core Web Vitals 无明显阻塞；WCAG 2.1 AA 基线问题已处理。
